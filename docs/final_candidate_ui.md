# 印なし最終候補UIの旧仕様について

通常予想画面の現行仕様は[レースピックアップ・全頭比較UI](race_comparison_ui.md)に移行した。

通常画面は現行Aを使用し、レースピックアップと全頭比較を中心に表示する。研究Bは独立した研究機能として保持する。過去走は**3走前 → 2走前 → 前走**とし、全頭一覧にも正式印・AI候補マークを表示しない。

旧仕様の通常画面のA/B切替、前走から順に並べる表示、全頭一覧に印を残す方針は、新仕様で置き換えられた。旧版の仕様・検証結果はGit履歴を参照する。最新の取得可能データ、欠損の扱い、選択操作、保護対象、検証方法は上記リンクを正とする。

候補選出・数値参照の既存処理`core/final_candidate_selection.py`と`core/final_candidate_metrics.py`は引き続き利用し、予測・保存データへ表示操作を書き戻さない。
