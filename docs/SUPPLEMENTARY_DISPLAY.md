# 補助表示 v2（表示専用・正式評価非接続）

正式順位・印・勝率・購入ナビ・保存考察を変更しない。表示計算は全頭のコピーだけに適用し、`_supplementary_display` に格納する。Snapshotには書き込まない。

## 展開有利

旧 `v1_pace_eval` は4角位置カテゴリの○/△/×。スコアの既存補正は維持し、表・カードの新しい「展開有利」と分離する。新表示の — は不利ではない。

保守的な説明用条件（効果未検証）：全頭の脚質が取得済みで、4角順位と保存位置カテゴリがあり、純能力5位以内または距離/コース指数3位以内の裏付けを要求。

- H：逃げ脚質2頭以上、逃げ先行計3頭以上。対象は差し/追込脚質かつ中団/後方想定。競り合いが生じる場合の条件付き利点。
- S：逃げ脚質ちょうど1頭、逃げ先行計2頭以下。対象は逃げ/先行脚質かつ前方想定。競らず運べる場合の条件付き利点。
- M・欠損・矛盾・その他：—。前方位置だけを根拠に◎にしない。

これらは位置以外の根拠を明示するための探索的表示で、好走率向上を立証した条件ではない。実4角・結果・オッズは使わない。

## 休養と厩舎コメント

休養は正確な保存日数を保持し、通常表示は60日以上のみ `約Nか月`（30日/月、切捨て）。180日以上では今回注意に「長期休養明け」を追加し、調教A/Bでも消さない。これは表示だけで、既存の70日＋調教C/Dによる正式判定は変更しない。既存の材料注意と印上限制御の理由は両方保持・重複除去する。考察本文の生成・保存版は変更しない。

厩舎評価は新聞の `table.Stable_Comment` の `td.Hyoka` の明示評価だけを取得。公式CSS/spriteを照合した `Icon_Mark_01=◎ / 02=○ / 03=△` を使用し、馬番と馬名を照合する。コメント本文・調教・正式印・未知アイコンから評価を作らない。未取得・競合時は「—」で監査理由を保持する。自動文節評価と「厩舎評価（試験）」を廃止。

新規予想の全計算終了後に新聞由来の評価・出典・HTMLハッシュ・監査理由だけをoverall_tableへ追加し、既存SnapshotのDataFrame保存経路で保持する。古いSnapshotには値を推定・追記しない。保存時に新聞印がなければコメントが存在しても「—」。新聞の再アップロードなしに原文から印を復元することはできない。

通常カードには短い休養・厩舎評価だけを表示。コメント原文は既存の詳細を開いて確認する。補助評価理由列・自動解析長文・展開未判定理由は通常表示しない。展開判定条件は変更せず監査出力へ残す。

## NAR

正式候補集合を保存値から参照。未取得なら推定しない。現行✓の条件と頭数制限を変更せず、対象外理由を表示する。

独立した参考注目：正式候補外・無印・純能力9位以下、距離とコース指数がともに3位以内、かつ保存された近況「持ち直し」または同条件過去走あり。優先順は距離/コース順位合計、純能力順位、元配列順。9頭以下1頭、10頭以上2頭まで。詳細表と対象カードに「未検証」の説明を伴って表示し、正式印・結論・購入判断には接続しない。
