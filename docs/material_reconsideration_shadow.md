# 好材料・不安材料とTop5再検討Shadow

正式スコア・順位・最終印・勝率・買い方には接続しない表示用研究レイヤー。
新規予想の全処理終了後に計算し、debug_infoの
`jra_material_reconsideration_shadow` / `nar_material_reconsideration_shadow`へ保存する。
過去Snapshotは保存値を表示し、未保存の場合は「未計算」とする。
ただし日本時間で当日開催のレースは、未保存・空のmaterial判定だけを保存済み入力から参考補完する。
元の予想作成時刻が発走前であることは引き続き必要。現在の着順・オッズ・外部取得情報は使わない。
補完時刻、元予想作成時刻、入力ハッシュとsame_day_saved_inputs_referenceを記録し、
当時保存されていた判定と区別する。正式予想・既存Shadowは再計算しない。
一度保存された非空のmaterial判定は上書きしない。翌日以降の自動補完も行わない。

## 判定と最大1組の比較

独立した好材料領域が2つ以上なら◎、1つなら○、0なら—。
独立した不安領域が2つ以上なら⚠、1つなら△、0なら—。
同領域の指標は重複加算しない。—は安全の保証ではなく、取得材料で該当なし。
欠損をゼロ・平均値に置き換えず、missingに理由を保存する。

NARの好材料：

- 保存純能力順位1〜3位
- 距離・コース・近3走の★・☆の全頭順位Top3が2項目以上（条件領域の1票）
- 近3走中2走以上が3着以内
- 4角想定が頭数の前1/3かつ予測ペースS/M
- 保存騎手コース複勝率30%以上、20走以上

NARの不安材料：

- 距離・コース順位とも全頭の下半分
- 前走6着以下、指数が2・3走前の双方より5点以上低下
- 4角想定が後ろ1/3かつ予測ペースS
- 保存騎手コース複勝率10%以下、20走以上

NARでは年齢・斤量・旧クラス表示・調教・休養による票を追加しない。
JRAは既存実戦Shadowの入力契約を再利用するが、NARとは別判定。
正式1〜3位、ペース×4角、条件Top3、調教A/B、確認できた休養復帰好走、
明示的な前走降級を好材料領域として扱う。
スロー×4角9番手以降、調教Dまたは90日以上休養×調教C/Dで対抗材料なし、
斤量前走比+2kg以上を不安領域として扱う。
休養と調教は同じ状態領域で重複しない。斤量・休養等1つだけで⚠にしない。
JRA障害・発走前時刻未確認は対象外。

比較は正式Top5外の好◎かつ不安⚠以外と、正式Top5内の不安⚠が両方存在する場合のみ。
追加は保存正式順位が最上位、比較対象は最下位。NAR同順位は保存純能力値、最後に馬番。
正式Top5が5頭に確定しない場合（5位同着等）や順位欠損時は交換しない。
正式集合は保存し続け、独立したshadow_top5へ最大1頭の交換を記録する。
