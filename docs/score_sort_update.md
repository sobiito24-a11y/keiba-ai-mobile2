# 印保証と表示専用スコア・全頭比較

JRAは既存の印処理後、正式1〜5位の無印のみ△を補完する。理由「正式Top5補完」を表示コピーに保持。順位/スコア/既存印/圏外候補は変えない。過去原本を上書きしない。

NAR表示はcore/nar_display_score.pyの固定モデル別基準で50+10*(raw-mean)/sd。勝率でもJRAと同尺度でもない。未知モデルは換算しない。上下限を切らず大小と同点を維持。表示は2桁、ソートは丸め前内部値。旧方式Top5外の未計算値を補完しない。

ソートは馬番でDOM行と詳細を紐付け、欠損は昇降順とも最後、同値は馬番順。並び替えで再計算しない。性齢・枠番は保存された事実のみを使う。買い目には従来入力のコピーを渡す。

NAR✓は既存の純能力6〜8位かつ4角6位以内を維持。3条件中2条件へ切り替えない。予想計算・データ収集・既存BATは対象外。
