# レースピックアップ・全頭比較UI

PC版・モバイル版に共通する通常予想画面の仕様。既存のAI候補を提示し、利用者が全頭の指数・状態・過去走・展開を比較して、購入馬と券種を決める。

この仕様は旧[印なし最終候補UI](final_candidate_ui.md)を通常画面について置き換える。旧仕様の「通常画面でA/B切替」「最終候補の横比較テーブルを中心に表示」「過去走は前走→2走前→3走前」「全頭一覧には正式印を残す」は適用しない。旧版の仕様・検証結果はGit履歴で参照できる。

## 通常画面と予測データの保護

通常画面は現行Aの既存の正式スコア・正式順位・候補集合を使用する。A/B切替は通常の購入判断画面から外し、「研究Bの検証（通常予想とは別）」から従来の研究用比較画面を開く。

A・Bの計算式、固定係数、正式順位、内部印、参考✓の条件、保存済み予測値は変更しない。Bのコードや保存データを削除せず、`.keiba`の既存形式・A/B復元との互換性を維持する。研究Bの保存復元と、旧アーカイブからの事後再計算は従来どおり区別する。

休養、調教C/D、4角想定7番手以下、利用者の✓を理由とした新しい加点・除外・降格は行わない。オッズ取込、買い目研究、結果照合は既存機能を利用する。

## 画面構成と操作

表示順は、レース基本情報、レースピックアップ、レース展開予測、純能力の見える化、全頭予想・比較一覧、一覧の選択行直下に開く共通の馬別詳細、折りたたみの詳細分析。

PCではピックアップを基本3列とし、展開・純能力を並べて確認できる。全頭一覧は広い比較テーブルとし、自分の✓・馬番・馬名を左側に固定して指数部分を横スクロールする。詳細の過去3走は横並びにする。モバイルでは幅に応じてピックアップを1列または2列、展開を縦配置、全頭一覧を各馬のカード表示に切り替え、詳細を縦に読める構成にする。

### レースピックアップ

`core/final_candidate_selection.py`の既存選出を再利用する。正式Top5から最大5頭と既存の参考✓から最大1頭、重複を除いて最大6頭を馬番順に表示する。参考がなければ追加しない。単純なスコア上位6頭への置換や、表示のための新しい✓は作らない。

JRAは既存の正式順位1〜5位、NARは既存の`pure_ability_top5_group`を使う。NARの参考選出と保存済み選択の優先規則は`nar_check_selection.py`のままとする。既存判定が複数の参考馬を持つ場合でも、このエリアに出す参考は従来の比較UIと同じ最大1頭である。

カードには正式印、新しい候補内序列、本命・対抗等の呼称を出さない。実際の枠色付き馬番、馬名・性齢・騎手、脚質・4角想定、JRAの調教、前走間隔、斤量と前走比、騎手変更、最大3件の根拠がある短い特徴、純能力指数を表示する。カードと全頭一覧は同じ馬別詳細を開く。

### 展開と純能力

展開は既存の4角想定・脚質・出走頭数を読む。4角順位`r`、出走頭数`n`に対する`floor((r-1)*4/n)`で「逃げ・先団」「好位」「中団」「後方」の4帯に配置し、欠損・範囲外は位置未取得とする。脚質別の候補も示し、脚質と想定位置を同一視しない。

ペースは保存されたH/M/S等の値が一致する場合に表示し、不一致・欠損時は保留する。逃げ脚質の確認頭数、保存ペースに応じた注意、ピックアップ馬の位置を短文で示す。新たなペース推定や正式スコアへの加点はしない。

純能力は全頭を対象に、既存指数の高い順に横棒・数値・既存順位を示す。共通の線形尺度はゼロを含み、負数はゼロの反対側、欠損は未取得として扱う。差を誇張する馬ごとの尺度や新しい補正値は作らず、指数を勝率として表示しない。

### 全頭一覧と自分の✓

全頭一覧は馬番順を初期表示とし、A最終スコア、純能力順位、距離指数、コース指数等で並び替えられる。正式印・AI候補・参考候補・レースピックアップの行別マークは出さない。A正式スコアと正式順位は数値として比較できる。正式値がない参考馬に、参考式の値を正式スコアとして代用しない。

過去走の順番は、一覧・共通詳細・既存の比較表示とも**3走前 → 2走前 → 前走 → 3走平均 → ★最高指数**とする。着順とタイム指数は別項目として扱う。

自分の✓は全出走馬に付け外しでき、頭数制限を設けない。全頭表示／自分の✓だけ表示、全選択解除に対応する。初回のレース表示は未選択で、AI候補を自動チェックしない。並び替えや詳細開閉で状態を失わない。

状態はJavaScriptの`Set`と、同一タブの`sessionStorage`にレースキー別で保持する。同じタブで同じレースに戻った場合は利用者が付けた✓を復元できる。保存領域が使えない場合も画面内の操作は継続する。✓はブラウザー内の比較操作であり、`.keiba`、予測結果、正式順位、AI候補、買い目データへ書き戻さない。✓の頭数によるBOX提案は作らない。

### 馬別詳細と既存分析

馬名・一覧行・ピックアップカードは、馬番で特定した同じ詳細処理を使う。基本情報、A正式値と指数、過去3走、条件別実績、状態・変更、厩舎コメント原文、AIの解釈、プラス・注意材料を分ける。原文は省略せず、改行と空白を保持してHTMLエスケープする。原文がなければ未取得とする。

従来の12分析は「詳細分析」に残す。対象は、最終候補、展開・4角、純能力、コース、距離、調教・状態、★指数、☆指数、3走平均、今回＋／−、斤量／騎手、新AI総合（研究）。通常画面へ同じ大型比較表を重ねず、必要なときに折りたたみを開く。

## データの参照元

`game_race_ui.build_view()`が既存の表示投影を作り、`race_explorer_facts.project(horse, raw_saved_source, race_info)`を呼ぶ。原文の抽出には加工済みの表示行ではなく対応する保存行を渡す。入力の辞書、過去走、監査済み材料は変更しない。

| 表示項目 | 参照元・欠損時の扱い |
| --- | --- |
| A正式値・候補 | 既存の正式値と`final_candidate_selection`。表示専用の参考スコアに置き換えない |
| 純能力、距離、コース | 既存`final_metrics`と表示用全頭順位。新しい指数を作らない |
| 過去3走 | `candidate_profile.facts()`の開催日前と確認できた走。日付、会場、芝ダート、距離、回り、着順、タイム指数、クラス原文を取得範囲で表示 |
| 3走平均 | 保存された`3走平均`等の既存別名を優先。JRAの同義列`平均指数`は許可し、NARの5走平均である`平均指数`は転用しない |
| 3走平均の欠損 | 日付確認済み3走の指数がすべてある場合だけ、既存の表示用平均補完を使う。補完の説明を表示し、保存値へ反映しない |
| ★最高指数 | 保存された`★最高指数`・`star_max_index`等。一般の最高指数や近3走最大値で代用しない。該当走・条件に矛盾せず値が一致する走にのみ★を付ける |
| 騎手 | 既存`candidate_evidence.audit.jockey`または`jockey_positive.inputs()`。前走騎手を今回騎手で補完しない。明示的な乗替情報だけある場合は「乗替・前走騎手未取得」 |
| 斤量 | 既存の監査済み今回／前走斤量と差。両方が確認できず、または保存増減と矛盾する場合は差を未取得とする |
| 調教 | 既存のA〜DをJRAのみ表示。NARは対象外 |
| プラス・注意、AIの解釈 | 既存の監査済み材料とprofile。新しい選出・昇格・除外条件にしない |
| 厩舎コメント原文 | 生の保存行の`stable_comment_raw`、`厩舎コメント原文`、`新聞コメント`、`厩舎コメント`、`stable_comment`、`馬コメント`。加工・要約用の`stable_comment_market`、`stable_comment_summary`や表示用コメントで原文を補わない |
| 枠色 | 明示された枠番または同じレース・馬名を照合した既存の新聞HTML取得処理。馬番から推測せず、不明・矛盾は無色 |

### 前走間隔の日付検証

日数は「今回開催日 − 直近の実出走日」の暦日数とする。数値の着順、競走中止、失格は実出走として扱い、取消・除外は使わない。今回以降の日付は過去走に含めず、さらに新しい実出走の有無が不明な走があれば間隔も未取得とする。

保存日数と日付由来の日数が異なる場合は「未取得（保存間隔と日付が不一致）」とし、既存監査で不一致となった値も別の補完で復活させない。

「中N週」は月曜始まりの開催週間に挟まる週数。例えば日曜から3週後の日曜は21日・中2週。短い間隔は連闘または日数、40〜50日は約1ヶ月半、60〜119日は30.4375日／月で丸めた約Nヶ月、それ以外は日数で表示する。JRAとNARで定義を変えない。

### 条件別実績と初条件

開催日前と確認できる保存過去3走の範囲で、次の4種類の実出走数・3着以内回数・未確認数を表示する。

| 条件 | 必須の一致 | 表示例 |
| --- | --- | --- |
| 同会場・同馬場・同距離 | 会場＋芝ダート＋距離 | 東京ダ1600m：1戦1回3着以内（近3走の範囲） |
| 同会場・同馬場 | 会場＋芝ダート | 東京ダート：2戦1回3着以内（近3走の範囲） |
| 同馬場・同距離 | 芝ダート＋距離 | ダ1600m：1戦1回3着以内（近3走の範囲） |
| 同会場 | 会場 | 東京（芝・ダート通算）：3戦2回3着以内（近3走の範囲） |

「ダ」と「ダート」は同じ馬場として正規化する。芝とダートは最初の3条件で混ぜず、同会場通算のみ範囲を明記する。必須条件・着順が不足する場合は未取得・未確認とし、生涯成績や不適性に読み替えない。今回距離を過去の最高指数の距離から推定しない。

今回と前走の確定した距離・馬場の違いは変更情報にできる。ただし、過去3走にダート・芝・ブリンカー経験がないことから「初」を推定しない。現在の保存データには全キャリアや装着履歴の十分な証拠がなく、初ダート・初芝・初ブリンカー・再装着は表示しない。追加するには全過去走または信頼できる明示的な初条件情報、今回と過去の装着情報を取得し、取得元と判定根拠を表示用処理へ渡す必要がある。
