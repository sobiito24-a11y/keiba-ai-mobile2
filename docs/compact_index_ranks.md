# 全頭比較・指数順位の上下2段表示（2026-10-23）

今回の変更は `feat/compact-index-ranks` のUI・表示処理に限定する。開始時mainはPC `78db9bbe424094f45cc672dc2197f9f6ee55b1f0`、モバイル `6e56a28d0a7591aab4384481893babb15ed6d338`。

## 表示と参照元

一覧と馬別詳細は同じ `race_explorer_columns.records()` を参照し、`race_explorer_common.comparison_index_html()` で同じ数値と順位を表示する。表示側で順位を計算せず、同順位や順位の欠番も既存値を保持する。

| 項目 | 既存の参照元 | 表示 |
| --- | --- | --- |
| JRA正式評価／NAR最終評価 | 既存の正式Aスコアと正式順位 | 数値の下に順位 |
| 純能力・距離・コース | 既存の `explorer_facts.metrics` / `final_metrics`、既存表示投影 | 数値の下に、その指数自身の順位 |
| 同場同距離指数 | 既存 `horse.star.value/rank` | 値があるレースのみ追加、独立した順位 |
| 別場同距離指数 | 既存 `horse.away.value/rank` | 値があるレースのみ追加、独立した順位 |
| 3走平均・★最高指数 | 既存の表示用metrics | 数値のみ。新しい順位を作らない |
| 4角想定 | 既存metrics／展開予測の番手 | 「11番手」等。順位マークなし |
| NAR参考スコア | 既存 `reference_score.kind == 'reference'` のvalue | 「参考スコア（正式評価外）」として独立表示、順位なし |

順位は1位「◎1位」、2位「○2位」、3位「▲3位」、4位以下「4位」等、欠損「―」とする。この記号は指数の順位であり、正式印や候補所属を表すものではない。数値の欠損は未取得とし、0・負数を保持する。
正式印・AI候補マークは一覧へ復活させない。NARの正式スコアがない馬に残る参考表示用6位以下は、正式評価の順位として表示しない。元の保存順位・内部印・参考値は変更しない。

同場／別場同距離指数は既存の近3走の条件別最高指数であり、保存された「★最高指数」とは別定義である。芝・ダート一致を追加条件として断定しない。これらの順位を★最高指数へ流用しない。

数値と順位の重複列をまとめて横幅を減らした。個別順位のソート・フィルターは共通操作欄に残し、未取得は両方向で末尾に置く。手動✓、固定列、上段の独立した折りたたみ、詳細への共通ナビゲーションを維持する。

## コンパクト表示

スマートフォンは自分の✓・枠番・馬番・馬名の固定列と可動列を狭くし、セル余白を減らす。チェック操作の高さ44pxを確保する。長い馬名・開催条件は省略せず折り返すため、内容によって行高は増える。
詳細は評価・指数と過去3走を基本3列で比較し、幅360px未満の過去走は縦に表示する。過去走は引き続き3走前→2走前→前走。着順・指数・開催条件・日付・クラスや厩舎原文を削らない。
