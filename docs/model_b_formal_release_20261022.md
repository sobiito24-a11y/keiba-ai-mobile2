## A/B保存と使い方

通常のPC一括生成経路はUIの選択とは独立してAを既存項目、Bを model_b_prediction に保存します。Bにはモデル版、係数ID、prediction_at（JST）、全頭スコア・順位・本印、寄与・欠損・入力ハッシュが含まれます。新規予測と事後再計算、予定発走時刻、計算時刻との前後関係を記録します。入力の取得時点が証明されない場合は prestart_inputs_verified=false のままです。

過去.keibaへの追加は新しいファイルにのみ保存します：

```powershell
python tools/add_model_b_to_keiba.py "元の予想.keiba" "研究B付き予想.keiba"
```

元ファイルの上書きと既存出力への上書きを拒否。既に固定されたBは保持し、破損・入力不一致は拒否します。Aの全項目と既存オッズはJSON値として完全一致を検査します。PC・mobileとも1つの.keibaからA/Bを切り替えられます。B入力不足時は理由を表示してAへ戻します。
