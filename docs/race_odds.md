# レースオッズ管理 v1

正式予想を変更せず、単勝・複勝・馬連・ワイドの観測を管理します。実購入・買い目生成・独立AIの呼出しはありません。

## 保存と復元

`.keiba` の各レース直下に `race_odds_v1` を追加します。`prediction_result` と既存の正式値は変更しません。

- `saved`: 新規保存時の観測。旧ファイルは保存済み単勝を時刻不明の参考価格として表示。
- `history`: 明示的な更新・取込で追加した観測。
- 保存時オッズを上書きせず、元ファイルとは別の履歴付きコピーをダウンロードします。
- Cloudセッション内の履歴は永続保存ではありません。ダウンロードが必要です。
- 不完全な観測には古い価格を補充しません。利用者が表示する観測を選びます。
- 取得失敗は画面に表示し、以前の観測・予想を維持します。
- HTMLの取込時刻と、HTML内にある提供元価格更新時刻は別のものです。

## オンライン更新の設定

正規提供元の取得・転送・表示許諾を管理者が確認できた場合のみ、Streamlit secretsに以下の接続情報を設定します。既存の `independent_ai_odds` 設定も後方互換として利用できますが、独立AIは実行しません。

```toml
[race_odds]
enabled = true
rights_confirmed = true
authorization_reference = "契約・許諾の識別情報"
source = "契約提供元の識別名"
endpoint = "https://your-authorized-provider.example/odds"
# token = "秘密情報。リポジトリへ保存しない"
```

これは接続仕様例であり、稼働する提供元や許諾を提供するものではありません。GETの `race_id` で全頭分を一括要求します。タイムアウト10秒、リダイレクト不可、応答2MB上限。更新間隔はセッション内30秒以上です。接続未設定時はボタンを無効にし、手動HTML/JSON取込を使います。

## 共通JSON

```json
{
  "race_id": "12桁の実レースID",
  "mode": "jra",
  "source": "契約提供元の識別名",
  "received_at": "2026-10-14T09:30:05+09:00",
  "observed_at": "2026-10-14T09:30:00+09:00",
  "identities": {"1": "実際の馬名", "2": "実際の馬名"},
  "withdrawn": [],
  "prices": [
    {"kind": "win", "horses": [1], "low": 4.5, "high": 4.5},
    {"kind": "place", "horses": [1], "low": 1.5, "high": 2.2},
    {"kind": "quinella", "horses": [1, 2], "low": 12.0, "high": 12.0},
    {"kind": "wide", "horses": [1, 2], "low": 3.0, "high": 4.0}
  ]
}
```

数値は形式説明用です。実際の取込では保存済みレースID・区分・馬番・馬名と一致する必要があります。タイムゾーンなし日時、NaN、プレースホルダー、競合価格、不明馬の価格は拒否します。取消・除外馬を含む価格は除外します。複数ファイルは全て照合後に一括反映し、失敗時は全体を反映しません。`odds_history`配列による複数観測の取込にも対応します。

提供元更新時刻不明の場合はnullを使用してください。取込日時で補いません。発走日時不明、古い価格、発走後、予想オッズ、発売終了は現在購入可能な価格と表示しません。

## ローカルCollector

通常の新聞等の取得後に、任意のオッズ処理が動きます。設定なしでも通常の予想生成は継続します。環境変数 `KEIBA_ODDS_CONFIG` またはCollectorの `--odds-config` に許諾設定JSONのパスを指定します。朝のpipelineは環境変数を引き継ぎます。

```json
{
  "enabled": true,
  "rights_confirmed": true,
  "authorization_reference": "取得を許可する契約等の識別情報",
  "pages": {
    "jra": ["https://race.netkeiba.com/odds/index.html?race_id={race_id}"],
    "nar": []
  }
}
```

設定は許諾の代替ではありません。NARや組み合わせページは、実際の公開URLと許諾を確認してから登録します。非公開APIは探索しません。最大4ページ、数値DOM待機最大15秒、ページ間2.5秒。ログイン・制限・別レースへの転送は停止します。成功・部分取得・未取得等を`.odds_status.json`へ記録します。

HTMLと`.odds.json`はタイムスタンプ付きの新規ファイルに保存します。DashboardのbuilderがJSONをレース単位で照合して保存時オッズへ追加します。オッズHTMLは予想入力から除外します。取得や照合の失敗で通常予想を停止させません。

## 対応範囲と未検証事項

- 実HTML確認済み：JRAスワンS `202608040511`。18頭の照合に成功、価格はプレースホルダーのみで有効価格0件。
- 単勝・複勝：既存新聞DOM・馬番を明示するオッズ表・名前付き表。
- 馬連・ワイド：馬番と馬名を明示する表、または共通JSON。netkeiba固有の動的組み合わせDOM全般を対応済みとはしていません。
- NARの価格入り実HTML、許諾済みオンライン提供元、Cloud接続、発走前実レースでの取得成功は未検証です。
- 許諾が確認できないため、この実装作業でnetkeibaへの自動アクセスは有効化していません。
- 通常画面には確率評価・購入推奨を追加していません。

利用条件確認先：[netkeiba利用規約](https://www.netkeiba.com/info/kiyaku.html?rf=footer)。公開ページの存在だけでは、自動取得・Cloud転送・再表示の許諾を確認できません。
