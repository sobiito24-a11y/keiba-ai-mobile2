# NAR AI推定勝率（参考） v1

正式予想・購入判断への入力にはしない。JRA勝率とは別モジュールで管理する。

- モデル: `nar_winprob_v1_20260922_71r_ability_avg`
- 入力: 保存済み `ver3_ability_core` と overall_table の `平均指数`（3走平均）。馬番で結合し、行順を使わない。
- score = 0.01838667 * pure_ability + 0.02653994 * average_index
- 確率 = exp(score - max(score)) / sum(exp(score - max(score)))
- オッズ・人気・結果・想定4角は使用しない。負の指数・0は有効値。
- 各特徴量が過半数の馬で取得できている場合だけ、個別欠損を29.2 / 22.0で補完する。各特徴量の半数以上が欠損、馬番重複、馬番欠損では全馬未取得。
- 内部は未丸め。表示は小数1桁（表示合計には丸め誤差があり得る）。

Snapshotにはscore、probability、model_version、実際に使った2特徴量を保存する。
.keiba復元時は保存モデルの確率を優先し、係数更新で過去確率を再計算しない。
既存履歴保存はデフォルトoverwrite=Falseを維持する。古い.keibaを一括更新しない。

## 再検証

`nar_winprob_validation_rows(snapshot, finishes)` へ馬番→確定着順の辞書を渡すと、保存確率・version・race_id・venue・馬番・馬名・実着順・勝敗を結合できる。結果は予測関数に渡さない。未確定・取消は勝敗None。
Mobile予想ZIPには `nar_winprob_validation.json`（結果未確定）を追加し、既存のresult_template.jsonと組み合わせて後日照合する。JSON/CSVの予想にも確率フィールドを残す。
