# スクリーンショットの単勝・複勝取込

外部OCR APIを使わず、Tesseract（jpn+eng）をローカル実行します。PNG・JPEG・WebP、最大5枚、1枚15MB／2,000万画素まで。日本語／英語モデルを確認し、罫線セル解析は120秒の予算（各セル10秒上限）、通常OCRは45秒上限で停止します。認識結果の自動確定はしません。

## 操作

1. 保存レースを選び、「スクショから単複オッズを取込」を開く。
2. PCでは貼り付け欄を選びCtrl＋V、またはファイル選択で画像を指定して「画像を読み取る」。iPhoneは写真選択を利用。貼り付けとアップロードの合計最大5枚。
3. 確認表の馬番・馬名・単勝・複勝上下限を画像と照合する。画像と保存済み出走馬一覧も展開できます。
4. 「1頭ずつ確認・修正」で要確認行から選び、元画像の行・セルを見て修正。「この行の修正を保存」。全頭一覧表も編集可能。欠損価格は空欄にする。編集後は全頭確認チェックが解除される。
5. 全項目確認のチェック後、「全頭一括反映」。
6. 既存の履歴保存欄から履歴付き`.keiba`コピーを保存する。

馬番・馬名は全出走馬との完全照合が必要です。レース名が写っていても照合を省略しません。OCR未導入・列見出し不明・認識失敗の場合は、手入力用の未取得表を表示します。保存馬名を読取馬名に自動転記しません。数字の人気順や行順を馬番へ代用しません。

単勝・複勝の列と馬番・馬名の明示見出しを確認できたレイアウトだけ解析します。見出しが読めないレイアウトは推測しません。低信頼文字は要確認と表示し、高信頼文字も確認必須です。複数画像の完全一致行は重複除外しますが、価格が競合する行は残して確認対象にします。

## 時刻・保存

- 画像取込日時だけを記録し、提供元価格更新日時は不明（null）のままです。
- スマホ時計・ファイル更新時刻・EXIF時刻を価格更新日時へ流用しません。
- 保存時オッズ、元予想、順位、印、考察を上書きしません。
- 既存の価格履歴へ単勝・複勝だけ追加。馬連・ワイドの過去観測は保持。
- 確認前OCR結果、確認後の表、画像SHA256、確認日時を履歴の監査情報として保存。画像そのものは`.keiba`へ埋め込みません。
- 新しい単複観測に過去の馬連・ワイド価格を混ぜません。過去観測は既存の観測選択で確認できます。
- 同一価格観測を再確定しても履歴を増やしません。

## 無料OCRの導入

Python追加パッケージは不要です。既存Pillow・NumPyとTesseractコマンドを使用します。

- Windows：Tesseractと日本語jpn・英語engモデルが必要。PATHまたは環境変数`TESSERACT_CMD`で実行ファイルを指定できます。言語データをユーザーフォルダに置く場合は`TESSDATA_PREFIX`で指定します。
- Community Cloud：repoルートの`packages.txt`へ `tesseract-ocr`、`tesseract-ocr-jpn`、`tesseract-ocr-eng`を追加しています。Cloud実デプロイは今回未実施です。

## 貼り付けの扱い

専用コンポーネント内のpasteイベントだけを使用。画像以外のデータは使わず、クリップボードを自動監視しません。画像はアプリのサーバー上で処理し、有料OCR APIや外部画像サービスへ転送しません。ブラウザー側・Python側で形式、15MB、2,000万画素の上限を検査します。非対応ブラウザーはファイル選択を利用してください。

## PC表の再解析と正式馬名の確認採用

列見出しが欠けた場合は罫線セル・列位置・保存出走馬の照合で下書きを作成します。人気列と馬番列が曖昧な場合は手動確認へ進みます。価格や馬名を推測して確定しません。

馬名不一致の行には、選択中の保存レース・馬番に対応する正式馬名の候補を表示します。対象レース・馬番・元画像・単複価格の確認チェック後に「確認して採用」を押すと、その行の馬名だけを変更します。画像からレースIDを読み取った保証ではありません。読取時の保存レースと現在のレースの識別情報が一致しない場合は採用できません。

採用操作は監査履歴に残り、元のOCR行を保持します。馬名を採用しても全頭数値の目視確認は省略できず、一括反映の確認チェックを改めて必要とします。予測・保存時オッズは変更しません。

実画像：PC12頭（取消1頭）は馬番12/12、価格33/33一致。馬名は5頭に誤読が残り、確認採用または手修正が必要です。PC18頭・8頭以下の実画像は未検証です。少頭数・18頭の文字座標テストとスマホ18頭画像は別の検証です。
