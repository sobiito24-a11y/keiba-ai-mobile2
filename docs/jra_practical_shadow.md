# JRA実戦再評価Shadow v1

正式モデルと完全に別の研究レイヤー。正式順位・スコア・印・勝率・ナビ・NARへ接続しない。

入力は予想生成完了後に馬番で結合し、horse_id競合・重複馬番は評価保留。
正式スコアは比較専用、数値評価の土台は保存された純能力。
再現性修正版・V2/V3のスコアや順位は使用しない。

固定研究仮説（54Rの結果に合わせた学習・最適化なし）：

- 4角×ペース：Sで1〜4番手+2、Sで9番手以降−1、Hで5〜8番手+1.5、Mで5〜8番手+0.5。それ以外は条件が取得できた場合のみ0。
- 条件：距離・コース・★・☆の取得値中Top3各+0.25。4項目が揃わない場合は欠損。
- 調教：A+0.75、B+0.25、C0、D−0.5。
- 既存の正式position bonus・展開bonusは加えない。基礎純能力から独立計算するため二重計上なし。
- 年齢、斤量、クラス変化、休養、過去走、直接対戦、当日馬体重は根拠・注意情報。単独で加減点しない。
- 休養90日以上でも一律減点しない。調教と取得可能な過去休み明け好走を併記。
- クラスは前走と今回の明示条件を比較できる場合のみ。旧降級フラグを流用しない。

欠損はNone。欠損件数を特徴量にしない。Bの数値比較では全頭に同じ取得済み評価軸を使い、1頭でも欠損する軸は全頭の比較から除外（個別説明は保持）。
純能力が欠ける馬がいればBを未確定とする。欠損を0や平均で埋めて選抜しない。

Aは正式1〜5位の保存集合。Bは全頭共通材料の独立評価上位5頭、同点は馬番。
CはAを基礎に最大1頭。Bの追加馬に2領域以上の好材料、除外側に明示的懸念があり、追加側の評価区間下限が除外側の上限を超える場合のみ交換。
欠損の不確実性幅は位置±2、条件±1、調教±0.75。区間の中点・下限をBの順位づけには使用しない。
条件4項目は相関するため好材料の1領域として数える。根拠が弱ければCは交換しない。

これは研究ZIPのFロジスティックモデルの製品化ではない。ZIPは54R既知結果を用いた探索で、欠損・対戦代理値の懸念もある。
新しい固定仮説としてバージョン分離した。54R比較は開発用参考再計算で、未来検証と呼ばない。

保存先はdebug_info.jra_practical_reevaluation_shadowとSnapshotの同名フィールド。
全入力、情報源、入力ハッシュ、時点確認、係数、評価日時、全頭理由、A/B/C・入替理由を凍結する。
表示は保存値のみ。旧Snapshotに未保存なら未計算。復元時に評価しない。
馬体重は当日取得日時があり、予測作成以前かつ発走前である場合だけ採用。

研究用実行例：

```text
python tools/evaluate_jra_practical_shadow.py --research <研究ZIP展開先> --output <repo外の検証出力先>
```

出力CSVは確定結果を評価後に結合する。研究ZIPの監査済み払戻を使用し、的中レースの払戻が欠損した場合はROI未確定。BOX10点・100円は検証の共通尺度であり、自動購入指示ではない。
