# AI独立判断 Ver.3 試験版

既存予想の計算終了後に独立評価を生成する。全頭対象で、正式順位・印・既存勝率・考察・Shadowを書き換えない。実購入機能はない。

## モデルと表示

JRA/NAR別に勝者の条件付きsoftmax、複勝払戻対象のロジスティックモデルを学習した。オッズ・正式順位・印・結果後の情報は入力しない。
能力、能力水準に対する適性・近況の差分、想定4角、母数を考慮した騎手率、休養・斤量を使用。JRAのみ調教。係数は過去の着順から学習し、正式順位を教師にしない。
ワイドは勝者分布からPlackett-Luceによる同時3着以内を近似する。複勝対象確率同士を掛け算しない。少頭数の複勝対象とワイドは区別する。
学習日を1日除外したモデル間の範囲を表示するが、統計的信頼区間や保証下限ではない。
全確率は「未校正・参考」。日付順検証は既知の過去データで、完全未使用検証ではない。有効な発走前価格がある場合、価格下限×モデル間確率下限が1.1を上回る候補から最大1点・仮想100円を表示する。これは既存の研究用制限で、利益実証済みの購入推奨ではない。余裕が不足する場合や価格が無効な場合は見送り。参考払戻倍率は利益優位性の証明ではない。

## 保存互換

新規予測の `debug_info.independent_ai_v3` に本文・全馬確率・根拠・入力・モデル版・ハッシュ・生成時刻を保存する。Mobile保存には同名の追加キーも収録する。
保存版はモデル更新後も優先。新キーがない旧データはセッション内で参考生成と明記し、旧ファイルは書き換えない。予測・オッズ・価格判断は独立JSONとしてダウンロードできる。
10/12以前は新AIの未使用検証に登録しない。発走前固定ボタンは時刻と入力ハッシュを検証し、ユーザーが固定JSONを保存する。Cloudの一時ストレージを永続保存とみなさない。

```
python -B tools/independent_ai_registry.py register fixed.json --root PATH
python -B tools/independent_ai_registry.py settle official.json --race-id RACEID --root PATH
```

同一レースの固定記録は上書き不可。結果は別ファイルへ結合し、保存済み仮想買い目だけを決済する。見送りの投資0円では回収率は未定義。

## オッズ提供元の調査（2026/10/12）

- JRA-VAN Data Lab.：月額2,090円のWindows向けサービス。JV-Linkと利用キーを使用する。単勝・複勝・ワイド速報がある。更新は券種・開催場を巡回するため、一律10秒の鮮度保証ではない。配信時刻と受信時刻の双方を保存する必要がある。
- JV-LinkはWindows COM。Debian LinuxのStreamlit Community Cloudへ直接接続可能とは扱わない。Windowsで正規取得してHTTPSで転送する構造も、個人契約の私的利用制限とCloudへの転送・表示の権利確認が前提。

## 共通接続口

未設定では「最新オッズ更新」を無効化する。契約・許諾確認済みの接続だけ管理者のsecrets設定で有効化可能。

```toml
[independent_ai_odds]
enabled = false
rights_confirmed = false
authorization_reference = ""
source = ""
endpoint = ""
# token はsecretsだけに置く。JSON保存へ含めない。
```

アダプターはrace_id指定HTTPS GET、リダイレクト禁止、10秒タイムアウト。応答は `race_id`, `source`, `observed_at`（timezone付き）, `identities`（馬番文字列→フル馬名）, `prices` を必要とする。各価格は `kind` (win/place/wide), `horses`（馬番配列）, `low`, `high`。取得日時は受信側で追加する。権利確認済み接続設定は管理者責任で、利用者の任意URL入力は設けない。

価格時刻から120秒を超過、未来時刻、発走後、時刻不明、レース不一致、不完全な範囲価格は採用しない。この120秒は運用上の保守的な制限であり、収益最適化した値ではない。複勝・ワイドは下限側を使う。

## ブラウザ保存HTMLの代替取込

実物JRA新聞で `odds-1_NN` と同じdl内の `Horse02` に馬名を確認した。一方、見出しが「予想オッズ」の実例があり、最新実売オッズと同一視しない。関東オークスNAR新聞の実例には価格数値がない。
canonical・og:url等の正本URL、JRA/NAR、馬番、フル馬名を照合。JavaScriptやHTML内ネットワーク命令は実行しない。
対応：確認済み新聞DOMの単勝、列名が明示された表の単勝・複勝・ワイド。複勝・ワイドの実物保存ページは未提供のため、表形式を合成テストした段階。別のDOM構造は推測で読まない。
価格時刻は明示された価格更新要素からのみ採用。ファイルmtime、アップロード時刻、ユーザー申告時刻から価格時刻を捏造しない。予想オッズ、未発売、取消、空欄、時刻不明を最新扱いしない。
保存時の明示的 `odds_at_prediction` と更新履歴は別管理。元データに保存時オッズがない場合、結果オッズから補わない。
HTMLは利用者のセッション内で解析し、アプリ共有領域への掲載・公開配信はしない。私的利用を超える運用には別途権利確認が必要。

## 2026/10/12 価格取込拡張

東京11R 202605040411の実物オッズHTML：horse_list JSONから16頭を識別、有効価格0件。JavaScriptは実行しない。人気順の要素IDを馬番と誤認せず、描画済み行の馬番を照合する。通常Ctrl+Sで価格が落ちる場合に備えて、単勝・複勝・ワイドの手入力と共通JSON取込を追加。手入力はフル馬名付き選択式、更新日時は利用者の転記と記録する。時刻が不明なら未取得のままで購入評価しない。iPhoneでもブラウザ表示を確認して手入力可能（実機試験は未実施）。

価格履歴JSONはダウンロードして再取込できる。同一観測の再取込では時刻を更新せず重複を除外する。券種ごとに取得組数/全組数を保持する。価格は組合せごとに新しい観測を使用し、古い価格の時刻を新しい取込時刻で置き換えない。

.keibaは元ファイルを選び「価格履歴付きコピーを作る」から保存する。各raceの追加フィールド independent_ai_odds_history のみ追加し、元のprediction_result/mobile_snapshotは変更しない。元ファイルそのものへ書き込まない。Dashboardは通常復元時に読み込み、Mobileは「保存.keibaからAI独立判断・オッズを開く」で選択する。

操作：保存レースを開く→AI独立判断を展開→HTML/JSON取込または手入力→価格評価と仮想候補/見送りを確認→履歴JSONまたは.keibaコピーを保存。未校正の参考候補・仮想候補と、実証済み推奨（現時点ではなし）を分離する。

正規の自動取得は未接続。無許可の内部APIやログイン回避を実装していない。NARの実物発売オッズHTMLは未検証。JSON・明示列テーブル・手入力はJRA/NAR共通テストを行う。取得アプリkeiba ai data本体の所在地は未確定のため、別アプリ側の画面組込は保留。
