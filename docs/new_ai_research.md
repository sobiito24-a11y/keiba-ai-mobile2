# 新AI総合（研究）：PC・mobile共通

正式スコア、正式印、Top5、既存✓、馬券選出、収集処理、.keibaスキーマは変更しません。
比較タブの「⑫ 新AI総合（研究）」から研究結果を閲覧します。
研究DBがない場合も通常画面は利用可能で、研究結果を未取得と表示します。

## 毎日の使い方（1ファイルで表示）

PCは「保存した予想を開く」で通常の.keibaを読み込みます。
`research/predictions.sqlite` または `research/portable` のレース別JSONを、元.keibaのSHA256・レースID・モデル版・設定ハッシュで自動照合します。
配置先変更は `KEIBA_RESEARCH_PREDICTIONS` / `KEIBA_RESEARCH_JSON_DIR` で指定できます。
別日の同一IDや異なる元ファイルの結果は流用しません。

iPhoneは「研究データ付き予想ZIP」を1回選択します。PCも同じZIPを開けます。
全レースの正式予想と研究結果を選択画面から切り替えられます。
旧.keiba単体も引き続き利用可能です。mobileはPCのDBを参照しないため、研究データがなければ未取得と表示します。
「詳細設定・研究JSONの手動復旧」は通常は操作不要です。

## 生成（既存収集と独立）

既存.keibaの完成後に実行してください。

```powershell
python tools/new_ai_research.py --keiba "保存.keiba" --stats "research.sqlite" --out "research/predictions.sqlite" --export-dir "research/portable" --bundle-dir "research/bundles"
```

Windowsの簡単な実行方法：

```bat
tools\new_ai_research_after.bat "保存.keiba" "統計DB\research.sqlite"
```

研究DB・JSON・研究ZIPはリポジトリ内のresearch配下に保存されます。
ZIP名は元ファイル名＋研究内容ハッシュで、内容が変われば別名になります。
同じ入力と固定予想では同じZIPとなり、再実行で重複を増やしません。
`--bundle "任意.zip"` による保存も可能ですが、既存ファイルと内容が異なれば拒否します。
固定SQLiteの更新・削除禁止と時点未確認の扱いは従来どおりです。

## 既存の起動手順から連続実行する場合

既存BATの代わりに、明示的に以下の独立ラッパーを起動できます。
既存BATの書換えや、稼働中プロセスへの組込みはしていません。

```bat
tools\run_prediction_then_research.bat "既存の起動.bat" "完成する保存.keiba" "統計DB\research.sqlite"
```

対象は引数不要・完了時に呼出元へ戻る既存BATです。非同期で起動だけして終了するBATや常駐型には適しません。
既存BATが失敗した場合、元.keibaが見つからない場合、今回の起動後に更新されていない場合は後処理を停止します。
新規ネットワーク収集は研究処理にはありません。ラッパーは利用者が指定した既存BATを呼び出すため、実際の収集を実行する意思がある場合だけ使用してください。
今回の確認は既存保存データでの後処理とテスト用BATでの連続実行です。実際のサイト収集は再実行していません。

## 研究ZIPの整合性

内容は `prediction.keiba`（原本バイトそのまま）、`research/<レースID>.json`、`bundle.json` のみです。
HTML・認証情報は梱包しません。.keiba内のschema_versionも変更しません。
外側ZIPと内側.keibaのハッシュ、JSONの内容ハッシュ・版・設定・馬番馬名を照合します。
パストラバーサル、重複ファイル、暗号化・リンク・不要ファイルは拒否します。
入力上限200MB、ZIP展開合計256MB、ファイル数512、研究JSON1件8MBです。
保存時刻だけで発走前情報とは判定しません。未知の取得時点は探索用です。
ハッシュは整合性検査であり第三者の署名・内容の真実性の証明ではありません。
研究ZIP・SQLite・原本は公開GitHubに含めないでください。

## 画面

⑫でモデルボタンを切り替え、研究Top5カード、順位変動、全頭の根拠を確認します。
必要な統計が足りないモデルは「未計算」と理由を表示します。他の計算可能なモデルは利用できます。
スマートフォンはカード1列、PCは画面幅に応じた複数列です。
NAR注目馬の説明は比較パネル直下に一度だけ表示し、探索候補は折りたたみます。

## 計算

JRAは保存された正式実数スコアに固定補正を加えます。
縮小3着内率=(3着内数+40×0.25)/(出走数+40)、補正=20×(縮小率−0.25)。
J_onlyは騎手、F1は騎手＋脚質、F2はさらに4角3区分±2、F3は数値4角の線形補正です。
71R代理脚質版と、今回の実着度数版は別版です。係数の最適化はしていません。
NARは保存正式順位Aと保存純能力基準のNAR_P系を区別します。JRA正式点尺度を流用しません。
必要統計が欠ける場合は研究順位を作りません。点数は勝率ではありません。

## NAR研究注目馬

正式Top5外の全馬を対象に最大2頭の独立仮説を実装しました。
純能力順位・4角位置による絶対除外はありません。
コース/距離指数上位3と、母数20以上・3着内率25%以上の騎手実績の条件を検証します。
このうちコース/距離条件を含む2材料を必要とし、コース・距離の相関を注意表示します。

**新条件は採用保留。採用注目馬は0頭です。**
探索比較で従来✓を上回らないため、検証候補だけを折りたたみ表示します。
対象4日から142Rが抽出されましたが44Rは保存済み正式順位がなく、再計算代用せず除外しました。
比較可能98R：正式Top5 490頭中224頭が3着内、勝ち馬78/98R。
従来✓112頭中30頭、新仮説88頭中14頭が3着内。
レースごとに小さい候補数へ揃えた61頭では従来17頭、新仮説12頭が3着内。
従来にない新規3着内7頭がある一方、全体改善はありません。
これを141R検証や将来性能の証明とは称しません。
結果を見て条件を再最適化せず、将来の未使用日で固定条件を検証してください。
