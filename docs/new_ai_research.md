# 新AI総合（研究）：PC・mobile共通

正式スコア、正式印、Top5、既存✓、馬券選出、収集処理、.keibaスキーマは変更しません。
比較タブの「⑫ 新AI総合（研究）」から研究結果を閲覧します。
研究DBがない場合も通常画面は利用可能で、研究結果を未取得と表示します。

## 研究結果の持ち運び

独立した後処理を実行します。既存BATへの組込みは行いません。

```powershell
python tools/new_ai_research.py --keiba "保存.keiba" --stats "research.sqlite" --out "research/predictions.sqlite" --export-dir "research/portable"
```

PCで作成されたレース別JSONと、元の.keibaをiPhoneへ転送します。
保存レースを開き「研究JSONを読み込む（PC・iPhone共通）」で両ファイルを選択してください。
元データSHA256・レースID・モデル版・設定ハッシュ・表示中の正式値を照合します。
ハッシュ照合は同一性検査であり、第三者の署名や発走前情報の証明ではありません。
入力変更時は別ファイルとなり、固定SQLiteは上書きしません。
古いHTMLで時点未確認の研究結果は探索用です。

## 計算

JRAは保存された正式実数スコアに固定補正を加えます。
縮小3着内率=(3着内数+40×0.25)/(出走数+40)、補正=20×(縮小率−0.25)。
J_onlyは騎手、F1は騎手＋脚質、F2はさらに4角3区分±2、F3は数値4角の線形補正です。
71R代理脚質版と、今回の実着度数版は別版です。係数の最適化はしていません。
NARは保存正式順位Aと保存純能力基準のNAR_P系を区別します。JRA正式点尺度を流用しません。
必要統計が欠ける場合は研究順位を作りません。点数は勝率ではありません。

## NAR研究注目馬

正式Top5外の全馬を対象に最大2頭の独立仮説を実装しました。
純能力順位・4角位置による絶対除外はありません。
コース/距離指数上位3と、母数20以上・3着内率25%以上の騎手実績の条件を検証します。
このうちコース/距離条件を含む2材料を必要とし、コース・距離の相関を注意表示します。

**新条件は採用保留。採用注目馬は0頭です。**
探索比較で従来✓を上回らないため、検証候補だけを折りたたみ表示します。
対象4日から142Rが抽出されましたが44Rは保存済み正式順位がなく、再計算代用せず除外しました。
比較可能98R：正式Top5 490頭中224頭が3着内、勝ち馬78/98R。
従来✓112頭中30頭、新仮説88頭中14頭が3着内。
レースごとに小さい候補数へ揃えた61頭では従来17頭、新仮説12頭が3着内。
従来にない新規3着内7頭がある一方、全体改善はありません。
これを141R検証や将来性能の証明とは称しません。
結果を見て条件を再最適化せず、将来の未使用日で固定条件を検証してください。
