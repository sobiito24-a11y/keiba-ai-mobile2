# 指標比較・コンパクト全頭UI

通常表示はレース情報→指標タブ→最大5頭カード→全頭表→選択馬カード→保存考察。今回の結論・独立AIは表示しません。内部の購入判断・予測・保存考察は維持します。

## 指標の正本
- 最終評価：既存のJRA正式順位1〜5、NAR正式候補フラグと正式順位。補助印から候補を推定しません。NAR境界同着で6頭なら候補を残し、上部だけ先頭5頭。
- 4角：既存netkeiba想定順位。展開有利判定とは別。
- 純能力：既存の純能力順位。
- コース／距離：既存の全頭内指数と競争順位。
- 調教：既存A→B→C→D、同評価は正式順位・スコア。NARは表示なし。
- ★：`condition_support.matching_recent_runs` / `annotate_condition_support` の直近3走・同会場同距離の最高指数。
- ☆：同じ既存処理の直近3走・同距離 **別会場** の最高指数。今回同会場を含める定義変更は行いません。元の実績一覧も入力・保存側に残します。
- 3走平均：保存済み `平均指数` 等を使用。再平均せず、全頭内競争順位（1＋自分より高い有効値の頭数）だけを表示専用に算出。

指数欠損を0にせず、未取得馬は上位カード対象外。0や負の有効指数は保持。各タブは最大5頭で補充なし。正式印は全タブで共通です。

## 枠番
新聞HTMLのcanonical/ogレースID、馬番、馬名、明示枠セルを照合。新規予想では全ての予測・Shadow生成後、任意の事実列 `frame_number` をoverall_tableへ付加します。既存の汎用表シリアライズと馬別メタデータで保存・復元し、スキーマの版や既存予測値は変えません。

旧ファイルには書き戻しません。枠番も元HTMLもない旧保存レースは「—」です。同一セッションの既存HTMLアップロードからの表示補完は継続します。手動照合と監査欄は `st.session_state.game_ui_debug=True` の場合だけ表示します。

## 操作・検証
全頭一覧は正式表示順を維持。タブの選択はブラウザ内だけで処理し、一覧DOM・予測を変更しません。カードクリックで詳細連動。表は約40px行、固定枠・馬名・ヘッダー、横スクロール。スマホの上部カードは横スクロールです。

`python -m pytest -q`

追加テスト：`test_game_ui_comparison.py`。既存の表示・保存テストも実行します。
