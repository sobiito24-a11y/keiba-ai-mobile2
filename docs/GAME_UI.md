# 全頭比較UI（表示専用）

Dashboard / Mobile は同じ `core/game_race_ui.py` と `core/game_ui_assets/` を利用します。

- 既存の詳細表レコードを正式表示の正本とし、順位・印・指数を再計算しません。
- 枠色は明示された枠番のみ。新聞HTMLは canonical / og:url のレースID、馬番、馬名を照合します。頭数や馬番から枠番を推定しません。
- 古い `.keiba` に枠番がない場合、同一レースの新聞HTMLを「枠番の新聞HTML照合」から追加できます。照合値は表示専用で、Snapshotには書き戻しません。
- 距離／コース記号は既存の全頭内指数順位バッジです。指数欠損を0として扱いません。
- 正式順位が存在しない正式候補外の馬は「—」。純能力順位で正式順位を代用しません。
- ✔︎と✓は別の印です。全頭の行・カードを保持し、ユーザーの行選択で表示だけを切り替えます。
- 行選択・カード詳細の開閉はブラウザ内で処理し、Streamlitへの予想再計算要求を送信しません。
- 独立AI Ver.3と馬の推定確率は通常画面に出しません。内部計算・モデル・監査データ・保存形式は維持します。
- 既存の購入判断と保存版レース考察をそのまま表示します。研究・監査項目と従来PNGは折りたたみに移動しています。
- 正式な全頭表示順を維持。スマホでも横スクロールの全頭表を残し、枠・馬名とヘッダーを固定します。

## 確認

`python -m pytest -q`

追加テストは `test_game_race_ui.py` / `test_game_ui_frames.py`。実データの表示確認では390px、768px、1280px、JRA18頭・NAR14頭を使用します。予想データとは別に出力したスクリーンショット・比較ログはリポジトリに含めません。
