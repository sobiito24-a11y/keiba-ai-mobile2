## 実装内容
- 白・ライトグレー基調、実枠色（不明は中立色）、印と馬番を強調した結論カード。既存印付き馬を全頭表示。
- 最終印候補は1行1頭。初期は先頭の◎、タップで直下に1頭だけ展開。同じ行で閉じる。別馬を開くと前の詳細を閉じ、スクロール移動を強制しない。
- 発走日より前と日付確認できた過去3走、指数推移、安定度★、クラス比較、直接対決、馬体重・休養・脚質・材料・コメントを表示。
- 6主要タブを維持し、既存★・☆・平均・材料・研究タブも残す。NARにも調教・状態タブを表示。
- 通常の馬カード・比較表からオッズを除外。市場・人気由来の材料コメントを表示から除外。手動オッズ取込は買い目検討用の折りたたみへ移動。買い目計算そのものは維持。

DesktopのJRA/NAR旧Notebookを確認。過去走・脚質等は現行 recent_races、class_context、newspaper_v2_enrichment に相当機能が存在するため再利用。新規サイトアクセスや重複収集は追加していない。新しく取得したデータは0件。保存データの表示・独立評価を拡充した。

## 独立参考条件
JRA参考注意馬：無印馬から、純能力/コース/距離の各上位5位、3走指数標準偏差≤5、保存調教Aのうち2項目以上。根拠数→純能力順位→馬番で最大2頭。固定の探索用条件で、正式加点なし。能力・コース・距離の重複があるため独立した予測力は未証明。
安定度★：3走のタイム指数標準偏差≤3/5/8/12/それ以上で5/4/3/2/1。3走不足は判定不可。これは能力水準や勝率ではない。
指数推移：最新に向け2区間とも3点以上増で上向き、2区間とも3点以上減で注意、それ以外は横ばい。3走不足は判定不可。調教・馬体重等を統合した状態スコアではない。
NAR✓は現行を維持。比較のみの2条件方式は正式Top5外の全馬対象で、純能力≤8、4角≤6、騎手複勝率≥25の2条件以上。現行の優先順で、比較ではレースごとの現行✓と同じ頭数を上限にした。
